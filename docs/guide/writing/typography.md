# 排版规范

> 这一页是这个模板真正区别于"直接抄 VitePress 默认配置"的地方。
> 技术内容再硬，排版糟也会让读者第一眼就失去信任。

## 一、中西文之间留空格

中文与英文单词、数字相邻时，加一个半角空格。

| 写法 | 结果 |
| --- | --- |
| 使用 VitePress 构建 | ✅ 正确 |
| 使用VitePress构建 | ❌ 拥挤 |
| 支持 20 种格式 | ✅ 正确 |
| 支持20种格式 | ❌ 拥挤 |

**例外**：中文与全角标点之间不加空格。

```md
✅ 运行 pnpm dev，然后打开浏览器。
❌ 运行 pnpm dev ，然后打开浏览器。
```

::: tip 本模板的自动处理
`zh-typography.css` 里用了 CSS 的 `text-spacing-trim` 属性，
浏览器会自动在中西文交界处插入约 1/4 字宽的间隙。
但这个特性**尚未在所有浏览器生效**，所以正文里仍然建议手动加空格——
自动处理只是兜底，不是替代。
:::

## 二、标点符号用全角

中文语境里用中文标点，不要混用半角。

| 场景 | 正确 | 错误 |
| --- | --- | --- |
| 句末 | `这是一个示例。` | `这是一个示例.` |
| 并列 | `安装、配置、运行` | `安装,配置,运行` |
| 引号 | `"引号内容"` | `"引号内容"` (直引号) |
| 括号 | `（补充说明）` | `(补充说明)` |

**例外**：代码、命令行、路径、配置项名内部，保持原样。

```md
✅ 在 config.mts 里设置 base。
❌ 在 config.mts 里设置 base 。
```

## 三、代码块标注语言

未标注语言的代码块没有语法高亮，读者体验直接降一档。

````md
```js          ← 必须标注
const a = 1
```
````

常用标注：`bash` `js` `ts` `vue` `json` `yaml` `python` `diff` `text`

### 终端命令与输出要分开

```bash
pnpm build
```

```text
✓ building client + server bundles...
✓ build complete in 8.42s
```

混在一个块里会让读者分不清哪行该输入。

### 用 `diff` 高亮改动

```diff
- const base = '/'
+ const base = '/my-repo/'
```

## 四、代码注释用中文，但标识符保持英文

```js
// ✅ 推荐：注释中文，命名英文
const userName = 'foo'  // 用户昵称

// ❌ 不推荐：变量名用拼音
const yongHuMing = 'foo'
```

## 五、标题层级不要跳级

```md
# 一级标题（每页仅一个，VitePress 用 frontmatter 的 title 也可以）
## 二级标题
### 三级标题
```

跳级（`##` 直接到 `####`）会破坏右侧目录的层级显示。
侧边栏的 `outline.level: [2, 3]` 表示目录只收录二、三级标题，
四级以下标题不会出现在目录里，**重要内容别只放在四级标题下**。

## 六、表格保持可读

中文表格最容易翻车的是**列太宽导致横向溢出**。

| 原则 | 说明 |
| --- | --- |
| 列数 ≤ 5 | 超过 5 列在笔记本屏幕上必然需要横向滚动 |
| 单元格不写长段落 | 段落改用列表或独立小节 |
| 对齐符号写全 | `\| --- \|` 保证渲染一致 |
| 内容含 `\|` 时转义 | 写成 `\\\|` |

本模板已配置单元格自动换行，但**列数过多的问题只能靠你控制**。

## 七、中英混排时链接文字用中文

```md
✅ 参考 [官方文档](https://example.com)
❌ 参考 [official docs](https://example.com)
```

读者是中文用户，链接文字也应该是中文（专有名词除外，如 `pnpm`、`GitHub`）。

## 八、数字与单位

- 数字与单位之间加空格：`10 KB`、`3.5 秒`
- 但百分比不加：`提升 20%`
- 中文量词不加：`5 个文件`

## 九、段落长度

中文单段建议**不超过 5 行**（约 100 字）。长段落会显著降低移动端阅读完成率。

超长的处理方式，按优先级：

1. 拆成多个段落
2. 改成无序列表
3. 改成表格
4. 加小标题分节

## 十、发布前自检

- [ ] 中西文之间有空格
- [ ] 中文标点用全角，代码内例外
- [ ] 所有代码块标注了语言
- [ ] 终端输入与输出分开
- [ ] 标题层级未跳级
- [ ] 表格列数 ≤ 5
- [ ] 没有超过 5 行的段落
- [ ] 专有名词大小写正确（GitHub 不是 Github，JavaScript 不是 Javascript）
