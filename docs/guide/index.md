# 简介

## vitepress-zh-starter 是什么

一个 VitePress 文档站模板，面向中文开源项目。

它做的事情是：把中文文档站的默认配置固定下来，让你新建项目时不用再调一遍行高、
字号、中西文间距、界面文案和搜索分词。

**没有引入任何额外依赖**，`package.json` 里只有 `vitepress` 一个包。

## 为什么用它

直接用 VitePress 默认配置搭中文站也能跑，但有几处需要自己处理。模板把这部分做完了：

| 场景 | 默认主题 | 本模板 |
| --- | --- | --- |
| 中文行高 | `1.5`，按英文调的 | `1.75`，段间距同步放大 |
| 中西文间距 | 无，需要手动打空格 | 自动加约 1/4 字宽 |
| 界面文案 | `TIP`、`Search`、`Prev`、`Next` | 全部中文 |
| 中文搜索 | 英文分词对中文失效 | 本地搜索按字切分 |
| 表格溢出 | 单元格不换行 | 允许换行 |
| 部署配置 | 需自己写 workflow | 附带 GitHub Actions |

这三项是模板的主要取舍：

- 主题用 `extends DefaultTheme` 而不是重写。VitePress 升级时你的改动不会失效。
- 中文排版集中在一个 CSS 文件（`zh-typography.css`）。删掉它就能回到官方默认外观，
  改坏了也容易回退。
- 不引入第三方插件。构建快，也没有供应链风险。

## 三十秒示例

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173`），
修改 `docs/` 下的任意 Markdown 文件，页面会自动刷新。

要发布到线上，推送 `main` 分支即可，GitHub Actions 会自动构建并部署。

## 能做什么，不做什么

**覆盖范围**

- 通用中文文档站：指南、参考、常见问题、更新日志、贡献指南
- 中文排版、中文搜索、界面文案中文化
- GitHub Pages 自动部署

**不包含**

- API 文档自动生成（需要配合 TypeDoc、JSDoc 等工具）
- 多语言 i18n（模板提供了配置示例，但默认不开启）
- 评论系统（`customize` 页有 Giscus 接入说明）

不内置多语言和评论是有意的：这两项都需要长期维护。没有稳定的英文贡献者却做半成品
英文站，比只做中文更伤信任；评论区长期没人回复，同样如此。
