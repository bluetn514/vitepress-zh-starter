# 更新日志

本页记录文档站模板的变更。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)。

::: tip 给读者的关键信息
更新日志最重要的不是罗列改了什么，而是告诉读者**升级会不会破坏现有用法**。
所以"变更"与"移除"两类要写清楚受影响的配置项。
:::

## [1.0.0] - 2025-01-01

首个版本。

### 新增

- 中文排版基线样式：行高 `1.75`、正文字号 `16px`、中西文自动间距
- 中文字体回退链，覆盖 macOS / Windows / Linux 三大平台
- 中文全文搜索（`local` 模式，零依赖、按字切分）
- 界面文案全面中文化：导航、搜索框、上一篇/下一篇、深色模式开关
- 自定义容器中文标题：提示 / 信息 / 注意 / 警告 / 详细信息
- 五段式文档结构示例：指南 / 写作规范 / 维护部署 / 参考 / 常见问题
- 中文文档写作规范三篇：排版规范、术语与用词、写作语气
- GitHub Actions 工作流，推送 `main` 自动部署到 GitHub Pages
- 死链检测开启，内部链接写错时构建失败

### 设计取舍

- **不引入额外依赖**：`package.json` 仅含 `vitepress`
- **主题用 extends 而非重写**：保证能跟随 VitePress 官方更新
- **排版改动集中在一个 CSS 文件**：删掉即恢复官方默认外观
- **不内置评论系统**：评论区需要长期维护，小项目开了反而伤信任

### 已知问题

- `text-spacing-trim` 在部分旧版浏览器不生效，中西文间距仍需手动加空格
- 孤立页面（未写入侧边栏）不会被死链检测发现

## 如何使用

替换成你自己项目的日志后，保留结构即可：

```md
## [未发布]

### 新增
- 新功能，读者能感知到的变化

### 变更
- 行为变化，**注明影响的配置项**

### 修复
- 修正的问题，附 Issue 编号

### 移除
- 删掉的能力，**注明替代方案**
```

::: warning 别写内部流水账
"重构了 xxx 模块""升级了依赖"对读者没有价值。
读者只关心：**我能做什么新事情、我的现有用法会不会坏**。
:::
